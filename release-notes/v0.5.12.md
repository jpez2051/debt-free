# Debt Free v0.5.12

This release broadens purchase entry into expense entry and improves native date-field sizing.

## Improvements

- Purchase actions are now labeled Expense or Add expense.
- Interest is available as an expense category and increases the selected credit-card balance like other card charges.
- Card-payment dates, next-payment dates, and statement-closing dates remain contained within their modal columns.
- Existing transaction data remains compatible; only user-facing terminology changes.

## Verification

- All automated tests, version validation, and the production build pass.
- Expense and date-entry layouts were tested at desktop and phone widths.
