# Debt Free v0.5.11

This release makes date entry faster and more consistent across desktop and mobile.

## Improvements

- Clicking anywhere in a date field now opens the device's native calendar picker.
- Calendar behavior covers purchases, income, transfers, card payments, payment due dates, and statement closing dates.
- Date-entry modals were verified at a 390 × 844 phone viewport without horizontal overflow.
- Windows checkouts can now run the release transform pipeline regardless of CRLF line endings.

## Verification

- Automated tests, release-version validation, and the production build pass.
- All affected date fields were exercised locally with no browser console errors.
