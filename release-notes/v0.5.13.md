# Debt Free v0.5.13

This release adds optional manual credit-score history to the Insights page.

- Record a score, date, source, bureau, and scoring model.
- Aura defaults to Equifax and VantageScore 3.0.
- Credit Karma and Citi presets remain distinct so unlike models are never compared as one series.
- Score changes are calculated only between entries with the same source, bureau, and model.
- The tracker remains local-first and is included in the existing Debt Free data object.
